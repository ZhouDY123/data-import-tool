# 订单导入台

本地运行的订单附件导入工具。它会登录三个店铺附件页面，下载当前附件，解析订单并在确认后调用对应平台接口。

## 启动

在此目录打开 PowerShell，运行：

```powershell
pnpm start
```

然后访问 `http://127.0.0.1:4173`。

## 使用顺序

1. 输入后台账号和密码，点击“获取并解析全部附件”。
2. 查看每个店铺的有效条数与异常条数。异常数据不会提交。
3. 核对预览表中的订单号、金额、时间和 SKU。
4. 点击相应店铺的“导入订单”。每批最多 200 条。

重复的“平台 + 店铺 + 订单号 + SKU”由目标接口覆盖更新。工具不会删除目标数据库中的历史订单。

## 已实现的附件映射

| 平台 | 文件 | 订单号 | 成交时间 | 金额 | SKU |
| --- | --- | --- | --- | --- | --- |
| 京东 | Excel | 订单号 | 付款确认时间 | 商家应收 | 商品 ID |
| 天猫 | Excel | 主订单编号 | 订单付款时间 | 买家实付金额，按子订单价格与数量分摊 | 商品 ID + 子订单编号 |
| 拼多多 | CSV（UTF-8） | 订单号 | 订单成交时间 | 商家实收金额 | 样式 ID |

账号与密码只存在于当次浏览器请求中，不写入文件、任务记录或日志。原始附件和导入任务会保存在 `data/`，方便追溯；该目录含订单数据，请只在受控电脑中保留。
